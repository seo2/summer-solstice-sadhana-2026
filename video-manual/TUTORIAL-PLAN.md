- Winter event: Dec 15–21, 2026 · Lake Wales, FL. No Ram Das Puri / June / altitude.
- Info hub is interim/generic: show the topic tiles, never zoom into specific page text.
- Production has 0 dishes and 0 announcements: Menus shows the daily menu only (no dish card);
  the Announcements scene needs one example post seeded through the mock backend, shown as
  an illustration (generic text, no real dates or names).
- Accounts / sign-in are hidden in the app: not shown.
- Favorite reminders (15 min before) exist only in the App Store / Google Play app: say so.
